# EtaFocus - Pomodoro & Todo Application

A modern Progressive Web Application combining Pomodoro timer functionality with an integrated todo list system.

## Tech Stack

- **React 18+** with **TypeScript**
- **Vite** for build tooling
- **Tailwind CSS** + **shadcn/ui** for styling
- **Vitest** for unit/integration testing
- **Playwright** for E2E testing
- **PWA** support with offline functionality

## Getting Started

### Prerequisites

- Node.js 18+ and npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view the app.

### Building

```bash
npm run build
```

### Testing

```bash
# Run unit tests
npm test

# Run unit tests with UI
npm run test:ui

# Run E2E tests
npm run test:e2e

# Run E2E tests with UI
npm run test:e2e:ui
```

### Linting

```bash
npm run lint
```

## Features

- Pomodoro timer with classic and custom intervals
- Todo list with task tracking

- Statistics and analytics
- Light/dark theme
- Sound alerts and notifications
- PWA with offline support
